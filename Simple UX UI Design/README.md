
  # AI-ActivEdu - Simple UX UI Design

  ## Legacy Notice

  This folder is a legacy UX prototype and is not the primary app.
  Use the main app in `frontend/` and run from repo root with `npm run dev`.
  The active frontend must be served on port `3002`.

  This is a code bundle for Simple UX UI Design. The original project is available at https://www.figma.com/design/2p6TjAZfhuelcAGHTeUGGR/Simple-UX-UI-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev:legacy` only when you explicitly need this legacy prototype.
